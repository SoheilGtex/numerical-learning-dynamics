# Results Index

The following catalog maps generated artifacts to the scripts that produce them. All results are synthetic and deterministic under the declared seed policies.

The exact dependency snapshot used for the packaged release is [`requirements-release.txt`](../requirements-release.txt). It is distinct from the flexible lower-bound dependencies in `pyproject.toml`.
