# Numerical Learning Dynamics

## Abstract

This repository develops a controlled numerical-modeling study from a classroom question: can a student's final Numerical Analysis grade be predicted from early-semester information? The work is not an empirical educational study. It uses synthetic data to examine the mathematical and computational issues that arise when linear prediction is estimated, solved, perturbed, regularized, and evaluated out of sample. Phase 1 establishes a least-squares baseline. Phase 2 compares Normal Equations, QR, SVD/pseudoinverse, and `numpy.linalg.lstsq`, including rank deficiency. Phase 3 measures conditioning and response/design perturbation sensitivity. Phase 4 studies centered SVD Ridge, strict validation/test separation, bias–variance behavior, and classical OLS interval coverage. Phase 5 returns to genuine held-out forecasting through nested information checkpoints, replicated ablation, and response/feature contamination experiments with OLS, Ridge, and transparent Huber IRLS. The results show that coefficient instability, fitted-value stability, parameter identifiability, estimation variance, and predictive generalization are distinct objects. Later synthetic information improved held-out forecasting in the executed study, while Huber was more resistant to the specified response contamination but did not universally dominate feature contamination. All conclusions are limited to controlled synthetic evidence; no actual student records or empirical educational claims are involved.

## 3. Mathematical Setup

For a design matrix with an explicit intercept, the baseline problem is

$$\min_\beta \|X\beta-y\|_2^2.$$

The least-squares solution is a projection of $y$ onto the column space of $X$. A coefficient vector is identifiable only when the relevant design representation has sufficient rank. Centered Ridge instead solves a penalized problem for the centered slopes,

$$\min_{\beta_c}\|y_c-X_c\beta_c\|_2^2+\lambda\|\beta_c\|_2^2,$$

while leaving the intercept unpenalized. Phase 5 uses nested feature sets $F_1\subset\cdots\subset F_4$ and fits

$$y=X^{(k)}\beta^{(k)}+\epsilon^{(k)},$$

where early-checkpoint coefficients are interpreted as information-set projections when omitted variables are present.

## 5. Phase 2 — Numerical Least-Squares Solvers

The explicit solver study compares Normal Equations, reduced QR, SVD/pseudoinverse, and the trusted least-squares reference across well-conditioned, Phase 1, near-rank-deficient, and exactly rank-deficient cases. In the exact rank-deficient case, minimum-norm SVD solutions achieve nearly zero residuals while differing from the chosen generating coefficient vector. The result is non-identifiability, not solver failure. The primary table is [`results/tables/solver_comparison.csv`](../results/tables/solver_comparison.csv).

**Figure 2.** [`results/figures/solver_coefficient_error.png`](../results/figures/solver_coefficient_error.png) is generated by `scripts/run_solver_comparison.py` and compares coefficient error across numerical cases. It illustrates solver-dependent coordinate error in the controlled systems; it does not establish universal solver rankings.

**Figure 3.** [`results/figures/singular_value_spectra.png`](../results/figures/singular_value_spectra.png) is generated by `scripts/run_solver_comparison.py` and shows singular-value behavior associated with rank loss. It does not establish rank behavior for external datasets.

## 6. Phase 3 — Conditioning and Perturbation

Phase 3 separates numerical conditioning from predictive generalization. The controlled sweep increases the design condition number toward near-rank deficiency, while fitted-value error is explicitly in-sample. Coefficient error and perturbation amplification increase sharply with conditioning, whereas fitted values can remain stable because the column space is nearly unchanged. The numerical values quoted for the most ill-conditioned cases are values from the packaged release environment; low-level Python/NumPy/LAPACK/BLAS/platform differences can be materially amplified in these deliberately sensitive regimes. The summary is [`results/tables/conditioning_summary.csv`](../results/tables/conditioning_summary.csv); raw and perturbation tables include [`results/tables/conditioning_sweep.csv`](../results/tables/conditioning_sweep.csv), [`results/tables/response_perturbation.csv`](../results/tables/response_perturbation.csv), and [`results/tables/design_perturbation.csv`](../results/tables/design_perturbation.csv).

## 7. Phase 4 — Regularization and Uncertainty

Centered SVD Ridge uses an unpenalized intercept, training-only standardization, and dimension-aware $\lambda=\alpha\sigma_{\max}^2$. Validation and GCV use training/validation information; the test partition is evaluated after selection. The accepted study shows the usual trade-off: regularization can reduce coefficient variance and perturbation sensitivity while introducing bias. The bias–variance figure uses normalized squared coefficient quantities, making bias squared, variance, and MSE dimensionally comparable. Selection and path outputs are [`results/tables/lambda_selection.csv`](../results/tables/lambda_selection.csv) and [`results/tables/regularization_path.csv`](../results/tables/regularization_path.csv); bias–variance outputs are [`results/tables/bias_variance_summary.csv`](../results/tables/bias_variance_summary.csv).

**Figure 7.** [`results/figures/regularization_path.png`](../results/figures/regularization_path.png) is generated by `scripts/run_regularization_study.py` and displays the Ridge path. It illustrates the executed synthetic shrinkage behavior; it does not establish a universally optimal regularization level.

**Figure 8.** [`results/figures/bias_variance_tradeoff.png`](../results/figures/bias_variance_tradeoff.png) is generated by `scripts/run_regularization_study.py` and plots normalized squared bias, variance, and MSE. It demonstrates the executed conditional bias–variance trade-off; it does not provide a general finite-sample theorem for other designs.

The uncertainty study distinguishes mean-response confidence intervals from future-observation prediction intervals. [`results/tables/uncertainty_coverage.csv`](../results/tables/uncertainty_coverage.csv) records the empirical check.

**Figure 9.** [`results/figures/ols_interval_coverage.png`](../results/figures/ols_interval_coverage.png) is generated by `scripts/run_uncertainty_study.py` and compares classical OLS interval coverage. It is conditional on the controlled Gaussian linear-model assumptions and is not an analytical Ridge or Huber interval result.

## 8. Phase 5 — Forecasting, Ablation, and Robustness

Phase 5 uses four nested synthetic information horizons and 20 deterministic clean replications. The current mean held-out RMSE table is:

| Checkpoint | OLS | Ridge | Huber |
|---|---:|---:|---:|
| Pre-semester | 1.839638 | 1.841547 | 1.839715 |
| Early semester | 1.568967 | 1.558670 | 1.568399 |
| Mid semester | 1.384252 | 1.379206 | 1.385090 |
| Later semester | 1.301504 | 1.296868 | 1.297964 |

Ridge had the lowest mean RMSE at the early, mid, and later checkpoints; OLS was marginally lowest before the semester, with all models close. Ridge RMSE reductions between adjacent checkpoints were 0.282877, 0.179464, and 0.082338. These values are from [`results/tables/forecasting_summary.csv`](../results/tables/forecasting_summary.csv) and [`results/tables/checkpoint_improvement.csv`](../results/tables/checkpoint_improvement.csv); no significance claim is made.

**Figure 10.** [`results/figures/forecasting_rmse_vs_checkpoint.png`](../results/figures/forecasting_rmse_vs_checkpoint.png) is generated by `scripts/run_forecasting_study.py` and shows mean held-out RMSE by information horizon. It demonstrates the executed synthetic generalization trend; it does not establish real student forecasting performance.

The strongest replicated ablation was removal of the combined assessment group, with mean RMSE increase 0.195090. This is predictive contribution conditional on the other modeled features, not a causal effect. See [`results/tables/feature_ablation_summary.csv`](../results/tables/feature_ablation_summary.csv) and [`results/figures/feature_ablation.png`](../results/figures/feature_ablation.png).

At 20% response contamination, mean clean-test RMSE degradation was 0.315006 for OLS, 0.156496 for Ridge, and 0.072448 for Huber. At 20% feature contamination, applied to raw training predictors before preprocessing, degradation was 0.088809, 0.103237, and 0.081602, respectively. The complete summary is [`results/tables/robustness_summary.csv`](../results/tables/robustness_summary.csv).

**Figure 11.** [`results/figures/response_contamination_robustness.png`](../results/figures/response_contamination_robustness.png) is generated by `scripts/run_forecasting_study.py` and shows clean-test RMSE under response contamination of training targets. It demonstrates the specified replicated robustness behavior; it does not establish immunity to arbitrary outliers.

**Figure 12.** [`results/figures/feature_contamination_robustness.png`](../results/figures/feature_contamination_robustness.png) is generated by `scripts/run_forecasting_study.py` and shows clean-test RMSE under feature contamination of training predictors. It demonstrates that Huber does not universally dominate leverage-type contamination; it does not establish general robustness guarantees.

## 9. Cross-Phase Synthesis

The progression is deliberate:

**least squares → solver stability → rank deficiency → conditioning → perturbation sensitivity → Tikhonov regularization → bias–variance → uncertainty → held-out forecasting → ablation → robustness.**

The solver experiments show why a mathematically equivalent least-squares objective can produce different coefficient coordinates under finite precision. Conditioning explains why small data perturbations can create large coefficient changes. Ridge addresses variance and sensitivity by accepting bias. OLS uncertainty quantification addresses a different question from regularization. Phase 5 then evaluates predictive generalization on untouched observations and studies incremental information and specified contamination. Numerical conditioning, algorithmic stability, statistical estimation variance, held-out generalization, and parameter identifiability are related but non-interchangeable.

## 11. Limitations

All data are controlled synthetic simulations. Feature distributions are illustrative, early checkpoints represent information availability rather than a time-series model, and early linear models may represent projections under omitted variables. No educational, causal, or real-student inference is justified. Huber does not solve all high-leverage contamination. OLS interval coverage was checked only under the controlled classical assumptions; Ridge/Huber analytical intervals were not claimed. Small cross-platform floating-point differences may occur.

## 12. Future Work

Restrained future work could include legally and ethically available external data, nonlinear learning-curve models, sequential estimation, bootstrap or conformal methods, stronger robust estimators, and preregistered empirical validation. These are not implemented in the current release.

## 13. Conclusion

The repository's main contribution is a coherent numerical progression rather than a claim of a universally best predictor. It makes visible how solution algorithms, rank, conditioning, perturbations, regularization, uncertainty, information availability, and contamination affect different mathematical objects. The accepted experiments support precise statements about these controlled synthetic cases: coefficient recovery can fail without fitted-value failure; Ridge can stabilize estimation while adding bias; classical interval types answer different questions; later information improved held-out forecasts in the executed Phase 5 study; and Huber helped most clearly under the specified response contamination. The release is therefore useful as a reproducible numerical-analysis artifact, while its synthetic scope limits any interpretation beyond the implemented simulations.
